Arquitectura Modular

13 sistemas singleton con responsabilidades claras — zero acoplamiento:

src/systems/ AudioManager.ts → 15+ sonidos + 5 temas (Web Audio API) EnemyManager.ts → 5 tipos, 5 patrones de movimiento IA WeaponManager.ts → 6 armas: spread, piercing, plasma... PowerUpManager.ts → 8 power-ups, drops ponderados WaveManager.ts → Oleadas + mini-jefes + boss final ScoreManager.ts → Combos 4x + popups flotantes DifficultyManager.ts → HP/Speed/Spawn escalan por oleada SaveManager.ts → Schema v4 + migracion automatica AchievementManager.ts → 20 logros event-driven InputManager.ts → Unifica teclado + gamepad + tactil GamepadManager.ts → Dead zones + analog + edge detect TouchManager.ts → Joystick virtual multi-touch SettingsManager.ts → 16 opciones con persistencia src/config/gameplay.ts → TODA la config declarativa (zero magic numbers)

Cada parametro del juego es configurable sin tocar logica de gameplay.

Mecanicas Simples, Diversion Real

El tip del hackathon: "Apuesta por mecanicas simples pero divertidas"

Dispara

6 armas distintas. Cambio instantaneo. Cada una con sensacion unica.

Esquiva

5 patrones enemigos. Proyectiles. Oleadas crecientes. Jefes.

Progresa

Combos x4. Mejoras. Power-ups. 20 logros por desbloquear.
