El Desafío

Crear un juego arcade completo, jugable, desplegado y testeado — sin dependencias externas de arte o sonido, usando exclusivamente tecnologías web modernas.

La Solución: Chrono Defender

  • Juego de disparos horizontal con progresión infinita de oleadas
  • Todo el arte generado proceduralmente con Phaser Graphics
  • Todo el audio sintetizado en tiempo real con Web Audio API
  • Persistencia completa en localStorage sin servidor
  • Soporte multi-plataforma: teclado, gamepad y táctil
  • Desplegado automáticamente en GitHub Pages con CI/CD

Arquitectura del Sistema

src/
├── config/gameplay.ts      ← Configuración declarativa de todo el juego
├── scenes/
│   ├── MenuScene.ts         ← Menú navegable con submenús
│   ├── PrototypeScene.ts     ← Loop principal de gameplay
│   ├── PauseScene.ts        ← Overlay de pausa con quit
│   └── OptionsScene.ts      ← 16+ opciones configurables
├── systems/
│   ├── AudioManager.ts      ← 15+ sonidos sintetizados
│   ├── EnemyManager.ts      ← 5 tipos, 5 patrones de IA
│   ├── WeaponManager.ts     ← 6 armas con spread/piercing
│   ├── ScoreManager.ts      ← Combos hasta 4x multiplicador
│   ├── WaveManager.ts       ← Oleadas + mini-jefes + jefe final
│   ├── DifficultyManager.ts  ← Escalado adaptativo por oleada
│   ├── SaveManager.ts       ← Schema v4 + migración automática
│   ├── AchievementManager.ts ← 20 logros event-driven
│   ├── InputManager.ts      ← Teclado + Gamepad + Táctil
│   ├── GamepadManager.ts    ← Dead zones + analog + edge detect
│   ├── TouchManager.ts      ← Joystick virtual multi-touch
│   └── SettingsManager.ts    ← Get/Set tipado con persistencia
└── ui/
    ├── TouchOverlay.ts      ← Controles visibles en móvil
    ├── AchievementNotification.ts ← Toasts animados
    └── WeaponSwitcher.ts     ← Cambio de arma con teclas 1-6

Audio 100% Procedural

Ningún archivo de audio. Todo sintetizado en tiempo real con la Web Audio API.

5 Temas Musicales

  • Menú: pad ambiental con filtro
  • Gameplay: bajo pulsante + arpegio
  • Jefe: distorsión + stabs disonantes
  • Victoria: fanfarria triunfante
  • Game Over: melodía descendente

15+ Efectos de Sonido

  • Láser: barrido de frecuencia
  • Explosión: ráfaga de ruido
  • Pickup: arpegio ascendente
  • Impacto: onda cuadrada grave
  • UI: tonos de dos notas

Máximo 12 nodos de audio simultáneos para prevenir clipping.
Degradación elegante si AudioContext no está disponible.
